# 6. Recognition Rather than Recall

**Definition**: Minimize the user's memory load by making elements, actions, and options visible.
The user should not have to remember information from one part of the interface to another.

**Accessibility Lens**: Users who navigate sequentially rely heavily on page structure to orient
themselves. Consistent structure, clear headings, and persistent labels reduce memory burden. Hidden
navigation (hamburger menus) forces recall of how to access features. Labels on form fields must
persist — not disappear once the user begins typing. Instructions should be near the elements they
describe. Context that a sighted user can glance back at must be equally available to users who
experience the page sequentially, without requiring them to navigate back through content. Related
elements must be grouped in a way all users can perceive — grouping conveyed only through visual
proximity forces the assistive technology user to remember relationships instead of recognising
them. The system should also remember information the user has already provided: re-entering data
after navigation, losing form input on back-button, or failing to preserve user preferences across
sessions forces unnecessary recall and re-entry.
