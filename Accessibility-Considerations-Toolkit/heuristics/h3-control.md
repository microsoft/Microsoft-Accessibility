# 3. User Control and Freedom

**Definition**: Users often perform actions by mistake. They need a clearly marked 'emergency exit'
to leave the unwanted action without having to go through an extended process.

**Accessibility Lens**: Users who rely on keyboards or assistive technology must be able to escape
modals, close popups, cancel operations, and undo actions. A dialog or overlay with no discoverable
way out leaves the user stranded. After dismissing an overlay, the user should be returned to where
they were before so they are not disoriented. Multi-step processes need a way to go back. Consider:
if the user accidentally triggers something, can they get out using only their assistive technology?
Imprecise pointer input or movement during magnification panning may increase accidental activation;
evaluate recovery without assuming the same difficulty for everyone. Actions must be reversible or
confirmed — an irreversible action without confirmation is a critical trap. The severity of a
control-and-freedom violation scales with the consequence: losing a preference setting is annoying,
losing unsaved work is devastating.
