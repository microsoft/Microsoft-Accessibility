# 4. Consistency and Standards

**Definition**: Users should not have to wonder whether different words, situations, or actions mean
the same thing. Follow platform and industry conventions.

**Accessibility Lens**: Custom controls should follow established conventions so users can predict
how they behave. Heading structure and navigation patterns should be consistent across pages — if
navigation is in one location on one page, it should be there on every page. Consistent interaction
patterns help all users build reliable mental models; inconsistency forces re-learning on every
page. Watch for specific consistency traps: the same action producing different results in different
contexts (e.g., a key that sometimes submits and sometimes navigates); UI elements that move between
pages or states (the search box is in the header on one page and the sidebar on another); multiple
redundant paths to the same action that confuse habit formation; and the lack of a clear, consistent
starting point the user can always return to. Rigid sequences may add effort when an access strategy
requires repeated navigation or input. Evaluate support for different task orders and recovery
without assigning a fixed workflow to everyone with a disability.
